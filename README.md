# 校园体育器材出入库管理系统

校园体育器材出入库管理系统主要用于管理校园常用体育器材的出入库业务，支持篮球、排球、羽毛球拍、乒乓球拍、网球拍等器材的管理。

## 功能

- 器材信息管理（增删改查）
- 入库和出库登记
- 库存盘点与调整
- 用户权限管理
- 数据统计报表

## 使用方法

1. 安装依赖：`pip install PyQt5`
2. 运行程序：`python main.py`
3. 登录账号：`admin` / `admin123`

## 项目文件

- `config.py` - 系统配置
- `database.py` - 数据库
- `auth.py` - 用户认证
- `equipment.py` - 器材管理
- `inout.py` - 出入库
- `inventory.py` - 库存
- `report.py` - 报表
- `ui.py` - 界面
- `main.py` - 入口
