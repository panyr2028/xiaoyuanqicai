# 校园体育器材出入库管理系统

## 简介

校园体育器材出入库管理系统是一款专门针对校园体育器材管理需求开发的信息管理软件，主要用于管理篮球、排球、羽毛球拍、乒乓球拍、网球拍等五类常用体育器材的日常出入库业务。

## 主要功能

- **器材信息管理**：器材的添加、编辑、查询、删除
- **出入库管理**：入库登记、出库登记、记录查询
- **库存管理**：库存查询、预警提示、盘点、调整
- **用户管理**：用户账号管理、权限控制
- **数据报表**：统计报表、数据导出

## 技术栈

- **开发语言**：Python 3.8+
- **GUI框架**：PyQt5
- **数据库**：SQLite（默认）/ MySQL（可选）
- **代码规范**：PEP 8

## 快速开始

### 1. 安装依赖

```bash
pip install PyQt5
```

### 2. 运行系统

```bash
python main.py
```

### 3. 登录系统

首次登录使用默认管理员账号：
- 用户名：`admin`
- 密码：`admin123`

## 系统截图

系统采用直观的图形界面设计，包含以下主要功能区：

- **数据面板**：展示关键业务指标
